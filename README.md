What Is This?
This repo supports the unofficial Signal peer group for Texas Highway Patrol Recruit School Class A-2027. It was put together by a classmate applicant who is a web developer. Not affiliated with the Texas Department of Public Safety in any way.
If you are going through the Texas DPS Class A-2027 hiring process and want to connect with other applicants, this is the place.

About the Group
The THP Class A-2027 Signal group exists so recruits can:
Connect with fellow Texas DPS Class A-2027 applicants
Share tips on the hiring process and timeline
Support each other through physical prep and academy prep
Stay informed on what to expect at each stage
